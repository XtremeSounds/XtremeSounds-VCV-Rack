# VCV Library submission checklist

Plugin slug: `XtremeSounds`

1. Publish this repository publicly on GitHub.
2. Confirm `plugin.json` version is `2.1.5` and the source repository at that commit builds successfully.
3. Run the GitHub Actions workflow and confirm the Windows x64 validation build passes.
4. Tag the exact release commit `v2.1.5`.
5. Open exactly one issue in `VCVRack/library` with title `XtremeSounds`.
6. In the issue, post the public source repository URL and state the release version/commit hash.
7. Keep that issue as the permanent update thread for this plugin.
8. For each future free-module update, keep existing module slugs stable, increment the plugin version, push the commit, and post the new version plus exact commit hash in that same thread.

Before submission, review the VCV Plugin Ethics Guidelines and verify that all artwork, names, code, and third-party material are cleared for VCV Library distribution.
